# Foyer hackathon build

1. Read [`docs/HACKATHON.md`](../../../docs/HACKATHON.md) and root [`AGENTS.md`](../../../AGENTS.md).
2. Implement the **outline of the whole product**, not one isolated path. Skeleton is enough; production depth is not required.
3. Each day deepens the whole system (§8). Do not cut day 1 to “two curls without a court.”
4. Guardian is a real protocol client in the principal’s house. Spawn is only a harness.
5. Onboarding success = non-empty inbox, not “read the spec.”
6. After a structural change, append a bullet to the Architecture change log in `AGENTS.md`.
